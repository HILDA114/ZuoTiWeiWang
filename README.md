# ZuoTiWeiWang · 做题为王

> 胜者为王，做题亦为王。

---

**20 秒。**

一道题。一个倒计时。没有任何解释。

20 秒是什么概念？

意味着你必须在题干读完的瞬间就已经理解，在理解的同时就已经判断，在判断完成之前，四个选项已经全部扫过一遍。

当这 20 秒归零，屏幕四周的血色红晕开始呼吸，震动与铃声同时抵达——

你才终于明白，这不是练习。**这是审判。**

有考生当场眩晕瘫坐，手指僵在屏幕上方。那一刻，他仿佛看到了整张答题卡被扫描仪一口吞没的画面。

---

## 世间一切，尽为做题


20秒60秒...区别只在于，有些人 20 秒，有些人一辈子。

考公，是把这一生压缩到极致的那次实验。20 秒，一道文字题，四个选项，一个正确答案。没有人告诉你题目究竟在考什么，没有人负责解释，时间一到，铃声响起——

**你就是本题唯一的答案。**
